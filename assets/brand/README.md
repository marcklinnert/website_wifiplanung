# Marken-Assets

Dieser Ordner nimmt **ausschließlich öffentliche, zur Veröffentlichung freigegebene** Marken-Assets auf. Das Repository ist öffentlich.

## Benötigte Dateien (noch nicht vorhanden)

| Datei | Format (bevorzugt) | Hinweis |
|---|---|---|
| WiFi-Planung-Logo | SVG, alternativ PDF/AI-Vektor | Originaldatei, auch zur Verifizierung der Farbwerte #0262B4 / #02ADF4 |
| BA-One-Logo | SVG, alternativ PDF/AI-Vektor | ggf. mit Markenrichtlinie |
| Porträtfoto Marc Klinnert | JPG/PNG in hoher Auflösung | nur mit Freigabe zur Veröffentlichung |
| Offizielles Ekahau-Logo | Originaldatei von Ekahau | nur gemäß den offiziellen Ekahau-Nutzungsrichtlinien |
| ECSE-Design-Badge | Originaldatei von Ekahau | nur gemäß den offiziellen Ekahau-Nutzungsrichtlinien |
| Ekahau-Nutzungsrichtlinien | PDF/Link | zur Dokumentation der zulässigen Verwendung |
| Referenz-/Kundenlogos | SVG/PNG | erst nach geklärter Veröffentlichungsfreigabe und korrekter Kategorie (Kunde, Partner, Arbeitgeber) |

Ekahau-Logo und ECSE-Badge werden später ausschließlich als **persönliche Qualifikation von Marc Klinnert** dargestellt, unverändert und ohne den Eindruck einer Unternehmenszertifizierung oder offiziellen Partnerschaft. Keine Nachbauten oder veränderten Logos.

## Nicht in dieses Repository

- das Originalzertifikat (PDF/Scan) und andere persönliche Nachweise
- Kundengrundrisse, Projektunterlagen, interne Planungsdokumentationen (z. B. Brudermühle-PDF)
- AP-Positionen, Kanalpläne, Sendeleistungen, Preislisten
- Logos oder Fotos ohne geklärte Nutzungsrechte

## Upload-Weg (nur Browser)

1. Auf GitHub das Repository öffnen und einen Feature-Branch auswählen (nicht `main`).
2. In den Ordner `assets/brand/` wechseln → **Add file → Upload files**.
3. Commit-Nachricht angeben und per Pull Request nach `develop` übernehmen.
